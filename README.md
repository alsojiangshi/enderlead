# Enderlead Mod
**Ender Lead** is a lightweight utility mod for Minecraft that adds a single, powerful item: the **Ender Lead** ― inspired by the version found in Apotheosis, but implemented as a standalone, minimal mod.

## Features
Adds the "Ender Lead" item, which allows players to capture and store any entity (not just animals) and release them later.

### Capture mechanics
**Left-click** an entity with the Ender Lead which will store that entity inside of the item.

Works on almost all entities, including mobs, villagers, modded creatures, etc. When an entity is captured, it is removed from the world and saved in the item's NBT data.

### Release mechanics
**Right-click** a block with the Ender Lead that has a stored entity and that entity will be spawned in at that position.

Each release consumes 1 durability point (each lead has 15 uses max).

### Additional Features
**Dynamic Tooltips:** Name of the entity stored will be in the Ender Lead's tooltip
**Enchant Glint:** When an entity is stored, the Ender Lead will glow with the Enchantment Glint effect
**Sounds:** Capturing or releasing entities will play the Enderman Teleport sound effect

## Crafting Recipe
The Ender Lead uses a shapeless recipe with 1 Lead, 1 Ender Pearl, and 1 Gold Ingot.

## Gameplay Impact
The Ender Lead offers a new way to interact with entities by significantly improving entity transportation and engagement:
- Easily move villagers, pets, bosses, or rare mobs across dimensions or long distances
- Build complex farms or bases with precise entity placement
- Capture mobs while exploring your world and release them back at your base
- Removes the need to use minecarts, boats, llamas, camals, or even regular leads in order to move mobs anywhere

This becomes especially usefor for technical and survival modpacks where controlling entity positions is critical.

## Design Philosophy
This mod is designed to be...
- ...**CLEAN** because it only adds one single item
- ...**INDEPENDENT** since it doesn't need other mods (like Apotheosis)
- ...and &&LIGHTWEIGHT** which makes it ideal for performance-conscious players and modpacks

## Credits
This mod is inspired by the **Ender Lead** from the Apotheosis mod, but implemented as a minimal and standalone version with the same core idea.
